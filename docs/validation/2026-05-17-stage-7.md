## Objective

Implement the strict video preview foundation: player-visible URLs must be local loopback token URLs, non-loopback bind addresses are rejected, proxy requests require the active token, and the app-owned chunk cache stays within a fixed memory budget.

## Scope Note

This stage implements the pure session/cache/proxy decision model only. It does not yet start a loopback HTTP server, spawn a real player, fetch remote video ranges, or inspect `ss`/`ps` output. The full tmux video smoke remains required when the server and player adapter are introduced.
